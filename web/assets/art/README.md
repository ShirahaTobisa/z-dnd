# z-dnd 美术素材

场景大图是 DnD 奇幻题材，2026-10-11 用 NovelAI 生成；布纹、黄铜零件、星图、标本页沿用原 z-coc 素材包（GPT 图像生成），它们没有题材色彩。各图的提示词见 `PROMPTS.md`。

## 使用原则

- 场景图只做低对比背景或卡片底图，上面叠深色渐变，保证文字看得清。
- 主色是近黑的海军蓝和木炭灰，黄铜色只做小面积高光。
- 网页只引用 `.webp`。新图沿用 `PROMPTS.md` 里的画师串，画风才统一。
